## ١. مقدمة عن الأداة

أداة **`change_ip.py`** هي سكربت متقدم، خفيف ومستقل بذاته، صُمم خصيصاً لمستخدمي شبكة **اتصالات الجزائر (Algérie Télécom)** سواء عبر الألياف البصرية (FTTH / Idoom Fibre) أو الـ VDSL / ADSL.

تتيح الأداة إعادة تجديد اتصال الـ WAN للحصول على عنوان بروتوكول إنترنت (IP) جديد بسرعة فائقة دون الحاجة لإعادة تشغيل المودم كاملاً، مع إمكانية استهداف نطاقات محددة، وتجاوز مشكلة عناوين الـ CGNAT المشتركة، واصطياد أفضل مسارات خوادم الألعاب لتقليل زمن الاستجابة (Ping / Latency).

### أبرز المزايا:
* **استقلالية تامة (Zero Dependencies):** تعتمد الأداة كلياً على مكتبات بايثون القياسية المدمجة؛ لا تتطلب تثبيت أي حزم أو مكاتب خارجية عبر `pip`.
* **توافقية شاملة:** تعمل على أنظمة **Linux**، و**Windows**، و**macOS**، وبيئة **Termux** على هواتف أندرويد.
* **دعم متعدد للأجهزة:**
  * **أجهزة Huawei:** (موديلات HG8145X6, HG8145V5, HG8245 وغيرها).
  * **أجهزة FiberHome:** (موديلات HG6145D2, HG6145F1, AN5506 وغيرها، مع معالج تشفير AES-128 مدمج).

## ٣. التشغيل الأولي ومعالج الإعداد (Setup Wizard)

لبدء تشغيل الأداة بالوضع التفاعلي:
```bash
python3 change_ip.py
```

عند أول تشغيل، ستبدأ الأداة تلقائياً في تشغيل **معالج الإعداد الذكي**:
1. **الاكتشاف التلقائي لعنوان المودم (Gateway IP):** يتم فحص الشبكة المحلية وتحديد عنوان المودم الافتراضي (غالباً `192.168.1.1` أو `192.168.100.1`).
2. **التعرّف التلقائي على نوع المودم (Vendor Detection):** تقوم الأداة بفحص واجهة المودم والتعرف على كونه Huawei أو FiberHome.
3. **بيانات الاعتماد:**
   - اختيار اسم المستخدم الافتراضي (مثل `telecomadmin` أو `admin` أو `user`).
   - إدخال كلمة المرور الخاصة بجهازك.
4. **التحقق والحفظ:** يتم اختبار تسجيل الدخول للتأكد من صحة البيانات، ثم حفظها في ملف إعداد محلي آمن (`~/.dz_router_optimizer.json`) لتفادي طلبها مجدداً في المرات القادمة.

> **ملاحظة:** لتغيير بيانات الاعتماد في أي وقت، يمكنك تشغيل الأمر مع المعامل `-c`:
> ```bash
> python3 change_ip.py -c
> ```
> أو الضغط على الزر `[0]` من داخل القائمة التفاعلية.

تتميز الأداة بإمكانية استخدامها عبر سطر الأوامر دون واجهة للمهام المجدولة (Cron jobs)، أو البوتات، أو السكربتات المخصصة:

### ١. التدوير الفوري لمرة واحدة والخروج:
```bash
python3 change_ip.py -r
```

### ٢. التدوير واشتراط الحصول على عنوان جديد يختلف عن الحالي:
```bash
python3 change_ip.py -r -u
```

### ٣. استهداف نطاق معين (مثال: نطاق 105 أو 154):

أو تحديد بادئة أدق:

```bash
python3 change_ip.py -r --public-only
```

## ٦. تشغيل خادم REST API للأجهزة والسكربتات الخارجية (`--serve`)

إذا كنت ترغب في تشغيل الأداة كخادم دائم في الخلفية على حاسوبك أو خادمك المنزلي، يمكنك تفعيل الـ REST API المدمج:

```bash
python3 change_ip.py --serve 8080
```

سيبدأ الخادم بالعمل على المنفذ `8080`، ويمكن لأي تطبيق أو كود أو بوت إرسال طلبات HTTP القياسية إليه:
* **معرفة حالة الاتصال:**
  ```bash
  curl http://127.0.0.1:8080/status
  ```
* **تنفيذ تدوير فوري للعنوان:**
  ```bash
  curl http://127.0.0.1:8080/rotate
  ```
* **تدوير مع استهداف نطاق محدد عبر API:**
  ```bash
  curl "http://127.0.0.1:8080/rotate?pool=105&public_only=1"
  ```

## ٧. ملاحظات وتنبيهات هامة لأجهزة اتصالات الجزائر

1. **أجهزة FiberHome (HG6145D2 و HG6145F1):**
   - تستخدم أجهزة فايبر هوم تشفيراً مخصصاً لكلمات المرور أثناء تسجيل الدخول عبر الويب؛ تم دمج خوارزمية التشفير القياسية داخل السكربت تلقائياً وبأداء عالٍ دون الحاجة لأي مكتبة خارجية.
   - يُفضل استخدام حساب `telecomadmin` إذا كان متاحاً لجهازك، أو حساب المستخدم العادي المطبوع أسفل المودم.
2. **عناوين الـ CGNAT:**
   - تبدأ عناوين شبكة المشاركة الداخلية بالبادئة `100.64.0.0/10` أو `10.x.x.x`. في هذه الحالة لا تكون المنافذ الخارجية (Port Forwarding) مفتوحة وتزداد فرصة تقطيع خوادم الألعاب. خيار `[3]` أو معامل `--public-only` يضمن لك دائماً الحصول على عنوان عام مفتوح (Public 1:1 IP).
3. **أجهزة Huawei:**
   - متوافقة تماماً وسريعة جداً في إعادة تجديد جلسة الـ PPPoE دون قطع الكهرباء أو إعادة إقلاع النظام.
